<h1 align="center">Nebula Launcher</h1>

<p align="center">
  Launcher de Minecraft: Java Edition gratis y sin anuncios, para Windows y Linux.<br>
  <strong>Web oficial y descargas: <a href="https://nebulalauncher.com">nebulalauncher.com</a></strong>
</p>

![Pantalla de inicio de Nebula Launcher: la isla de bloques, tus instancias y lo último a lo que jugaste.](https://nebulalauncher.com/img/inicio.webp)

- **Taller de skins en 3D.** Pinta sobre el muñeco o en el mapa plano, con diez herramientas, espejo, capas y un buscador para encontrar la skin de cualquier jugador por su nombre.
- **Tus amigos, dentro.** Solicitudes de amistad, chat con historial y perfiles. Si un amigo te pasa la IP de un servidor, la pulsas y el juego arranca ya dentro.
- **Mods sin líos.** Mods, shaders, packs de recursos y modpacks de Modrinth, que se instalan con lo que necesitan. Cada versión del juego va en su instancia, con vanilla, Fabric, Quilt, Forge o NeoForge, y Nebula baja el Java que pide cada una.
- **Seguro.** Inicias sesión en la propia web de Microsoft: Mojang revisó Nebula y lo añadió a la lista de su API. Con el instalador se actualiza solo, y cada actualización va firmada.

Cada versión se publica en la web con su huella SHA-256, para comprobar que tu descarga es la buena: https://nebulalauncher.com/seguridad

Este repositorio es la página de Nebula Launcher en GitHub. No tiene el código, porque Nebula Launcher no es de código abierto, ni los instaladores, que están en la web.

Nebula es un proyecto independiente. No es un producto oficial de Minecraft ni tiene relación con Mojang Studios ni con Microsoft. Para jugar en línea necesitas tener Minecraft: Java Edition.
